# PerceptLab

Personal visual-perception self-assessment toolkit (Next.js 16). Local-first: IndexedDB only, no backend, not a diagnostic device.

## Develop

```bash
npm install
npm run dev
```

```bash
npm test
npm run build
```

## Modules

- **A** Symptoms — CI-inspired + visual-stress checklists  
- **B** Pattern glare — calibrated Canvas square-wave gratings  
- **C** Reading — WRRT-inspired passages, cwpm + per-line timing  
- **D** Interventions — overlays, fonts, spacing, ruler + Latin-square phases  
- **E** Binocular — NPC logging + digital saccade baseline  
- **F** Journal — real-world triggers (local photos)  
- **G** Analytics — charts, stats, print summary  

See `perceptlab_design_doc.md` for full design rationale.
