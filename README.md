# PerceptLab

Personal visual-perception self-assessment toolkit (Next.js 16). Local-first: IndexedDB only, no backend, not a diagnostic device.

## Areas

1. **Assess** — calibrate, symptoms, pattern glare, paper-style reading baseline, binocular, journal  
2. **Find what helps** — adaptive staged search guided by Assess signals  
3. **Playground** — free parameter exploration (promote into Find if useful)  
4. **Insights** — trends, comparisons, clinical summary, export  

## Develop

```bash
npm install
npm run dev
```

```bash
npm test
npm run build
```
